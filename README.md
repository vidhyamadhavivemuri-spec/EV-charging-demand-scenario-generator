# EV Charging Demand Scenario Generator

This project generates small, reproducible EV charging-demand scenarios from a given seed and number of vehicles.

The project uses the fixed Linear Congruential Generator (LCG) specified in the project brief. For each vehicle, two pseudo-random values are generated:

* one for the arrival bucket
* one for the charging energy

The same seed and vehicle count always produce the same scenario.

> **Note:** The data generated by this project is completely fictional and is intended for learning and simulation only.

---

## What the Project Does

For each vehicle, the program generates:

* **Arrival bucket:** `0` to `3`
* **Energy demand:** `1` to `5 kWh`

It then calculates the total energy demand of all generated vehicles.

For example, with:

```json
{
  "seed": 0,
  "count": 1
}
```

the generated scenario is:

```json
{
  "arrivals": [0],
  "energy_kWh": [2],
  "total_kWh": 2
}
```

## Input Format

The program accepts a JSON file containing two required fields:

```json
{
  "seed": 0,
  "count": 1
}
```

### `seed`

The starting state of the random-number generator.

Valid range:

```text
0 to 4294967295
```

### `count`

The number of vehicles to generate.

Valid range:

```text
1 to 25
```

An empty scenario is not allowed.

Unknown input fields are rejected instead of being silently ignored.

---

## Random Number Generation

The project uses the following fixed LCG:

```text
state = (1664525 × state + 1013904223) modulo 2^32
```

After each update, the state is converted into a uniform value:

```text
uniform = state / 2^32
```

For each vehicle:

### 1. Arrival

```text
arrival = floor(uniform × 4)
```

This produces one of:

```text
0, 1, 2, 3
```

### 2. Energy

```text
energy = 1 + floor(uniform × 5)
```

This produces one of:

```text
1, 2, 3, 4, 5 kWh
```

Two LCG draws are therefore used for every vehicle.

## Worked Example

For:

```json
{
  "seed": 0,
  "count": 1
}
```

the first two LCG states are:

```text
1013904223
1196435762
```

These produce:

```text
arrival = 0
energy = 2 kWh
```

Therefore:

```json
{
  "arrivals": [0],
  "energy_kWh": [2],
  "total_kWh": 2
}
```

Using the same seed and count again produces the same result.

## Validation

The program checks the input before generating a scenario.

Examples of invalid inputs include:

* missing `seed`
* missing `count`
* unknown fields
* seed outside the allowed range
* count outside the allowed range
* `count = 0`
* non-integer seed or count

For example, an input containing only:

```json
{
  "seed": 0
}
```

is rejected with:

```json
{
  "status": "invalid",
  "reason": "missing_required_field",
  "fields": [
    "count"
  ]
}
```

## Scope and Limitations

This is a small simulation project based on the rules provided in the project brief.

The generated values are fictional and should not be interpreted as real-world EV charging demand.

The project does not use:

* real EV charging data
* live charging stations
* machine learning
* external APIs
* hardware
* commercial datasets

The goal is to demonstrate deterministic scenario generation, input validation, and basic testing.
